# 🏐 體感丟球大作戰

對著攝影機把手由下往上甩就能丟球！角色在畫面上方左右來回走，碰到邊緣就降一格；把他打回去、打光血量就過關，讓他越過紅色防線你就輸了。

- 角色可選男生／女生，並可上傳長相照片當大頭（照片只存在瀏覽器，不上傳）
- 攝影機手部追蹤（MediaPipe HandLandmarker），畫面會顯示你的手部骨架
- 無攝影機時可用滑鼠／觸控：往上拖曳放開＝丟球，點一下＝瞄準丟
- 3 關、本機排行榜、丟球靈敏度可調、可加入主畫面（PWA）

直接用瀏覽器開 `index.html`（攝影機需在 `localhost` 或 HTTPS 下才能使用）。操作說明見 `manual.html`。
